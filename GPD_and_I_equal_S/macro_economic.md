庸俗经济学：两部门经济的储蓄—投资恒等式的荒谬性，以及马克思经济学所能得出的新储蓄—新库存恒等式。

在这个两部门模型中，只有两大部门：消费者即家庭，企业即厂商。

而这时，国内生产总值等于国民收入，表示为Y。

据说：

> 从支出方面看，Y = C + I。
> 从收入方面看，Y = C + S。

然后通过毫无疑问的Y的相等，联立上述两个等式，并消去C，可得I = S恒等式。

这个公式十分古怪。我们不妨从最基本的经济内容，来验证这些数学关系。

---

从支出方面看价值关系，新价值总量 = 消费资料与服务的价值 + 生产资料（已增加与已更新）的价值 + 库存商品（包含消费资料与生产资料）的价值

从收入方面看价值关系，新价值总量 = 工资 + 利润 = 已消费比例 * （工资 + 利润） + 已储蓄比例 * （工资 + 利润）

现在假设新生产出来的价值为10000，那么，按照特定的利润与工资的比例，实际上就是剩余价值率，比如1: 1，来分配这里的新价值，可得新价值的收入情况如下：

新价值总量 = 工资总量 + 利润总量 = 5000 + 5000。

再从新价值的收入方面或者说用途方面来看，假设工资的消费率与储蓄率分别为80%与20%，其总额为单位1，利润的支出率与储蓄率分别为80%（其中，个人消费支出率为）与10%，其总额为单位1。

作为收入的新价值总量 = 总消费 + 总储蓄
=（工资总量 * 工资的个人消费率 + 利润总量 * （利润的个人消费率 + 利润的生产消费率）） + （工资总量 * 工资的储蓄率 + 利润总量 * 利润的储蓄率）
= （工资的个人消费额 + 利润的个人消费额 + 利润的生产消费额） + （工资的储蓄额 + 利润的储蓄额）
= （5000 * 80% + 5000 * （20% + 70%）） + （5000 * 20% + 5000 * 10%）
= （4000 + 1000 + 3500） + （1000 + 500）
= 8500 + 1500
= 10000

作为支出的新价值总量 = 总消费 + 总投资
= 总个人消费 + （利润的生产消费额 + 库存商品额）
= （工资产生的总个人消费额 + 利润产生的总个人消费额） + （利润产生的总生产消费额 + （工资的储蓄额 + 利润的储蓄额））
= （4000 + 1000）+ （3500 + （1000 + 500））
= 5000 + 5000
10000

我们仔细地写出了这两个计算方式在运算上的几乎每一个必要步骤，以免擅长数学的庸俗经济学家不能理解这里的数学关系。

现在我们来真正找寻作为收入的和作为支出的新价值总量之间的一些关系。作为收入的新价值总量中的总消费的数量是8500，其余的总储蓄为1500，因为相比于作为支出的新价值总额的相关计算方式，该计算方式将利润的生产消费额也算在了总消费之中。相反地，作为支出的新价值总量中的总消费额只包含个人消费，不包含生产消费，因为后者属于总投资，其总消费额为5000，其余的总投资为5000。

我们真正具体地来分析作为收入的和作为指出的新价值总量中价值的构成关系，就能发现，在二者的不同语境下，二者的总消费的意义是不同的，而总储蓄或总投资的计算方式也是不同的。

因此，庸俗经济学所谓的储蓄—投资恒等式，完全是胡说八道，毫无逻辑和依据。只是因为在这二个计算方式中，采取了两个同名的变量而已，这两个同名变量的经济内容和计算方式是不同的。然而烂俗经济学却依据它们的同名，任性地将它们伪装成为同一个东西。

不过，如果我们仔细观察这里的真实的经济关系，却有意外的发现。劳动者和资本家都可能进行储蓄，比如在这里的模型条件下，他们这二大群体分别储蓄了1000和500。应该不难发现，这个总的储蓄额，即为库存商品额。因为商品中新形成的价值，虽然已经被付给了劳动者或资本家，但没有被他们完全地花出去，而是各自留了一部分，即相应的储蓄额。

---

我必须提前抵冲一个谬论，即要求消费者特别是普通劳动者拼命消费，以减少库存，防范生产过剩。

我们这里讨论的是新生产的价值，而默认排除了旧价值的运动。仅以新价值的投资来看，其实，利润所产生的总生产消费额3500相对于新价值总额10000已经不算低。这个3500的总生产消费额，是用来再生产特别是扩大再生产。因此，这个投资关系已经可以保证生产的维持特别是扩大。问题只是在于：在资本主义关系下，由于存在特定量的储蓄，不管是劳动者的储蓄还是资本家的储蓄，就一定要产生过剩的商品，其价值不能得到完全的实现。（仅以此模型而言。）

现在，我们还需要讲清楚，特别是对庸俗经济学要讲清楚：这里的劳动者和资本家的二大类，不代表每一类只有一个人，而只是作为类而言的。我们可以引入一个比例，劳资人数比，来表示这两类群体之间人数上的比例关系。假设劳资人数比为100:1，即每个资本家对应100个劳动者。那么，二者的储蓄额以这个比例来平均，可知，每个劳动者的储蓄额=1000 / 100 = 10，每个资本家的储蓄额=500 / 1 = 500。现在，总的储蓄额不仅分为劳动者和资本家这两大类群体的储蓄额，而且还对应到每一个人头上。现在从每人的储蓄额就不难看出，我们应该冲着什么群体要求他们降低储蓄率。因此，像庸俗经济学家那样，冲着本来就没有多少积蓄的劳动者，叫嚷什么“为了刺激经济，你们一定要大手大脚拼命消费”，在一定意义上就找错人了。应该找积蓄甚多的资本家，恳求他们松开自己的钱袋，不管是用来生产消费还是个人消费。

不过，从比较客观的角度而言，资本家的投资和劳动者（以及资本家）的消费，对于资本主义的生产循环，都有其相应的作用和意义。所以，投资可以拉动经济，消费也可以拉动经济。投资是更多地生产新价值，消费是争取更好地实现商品中凝结的新价值。

---

另外，新价值的上述模型只考虑了企业主和劳动者两大群体，或者说，资本家和无产者两大阶级。就算我们加入金融资本家放出贷款收取利益者，也没有什么困难。

增设一个变量，利息率，比如设定为5%，参加上述模型。根本来看，利息来自剩余价值，然而直接来看，利息是从产业资本家那里拿到的，所以利息率会影响利润率和利润量。

新价值总量 = 工资 + 利润 + 利息
= 5000 + 5000 * 95% + 5000 * 5%
= 5000 + 4750 + 250

设金融资本家的个人消费率、投资消费率、储蓄率分别为40%、50%、10%。那么：

作为收入的新价值总量 = 总消费 + 总储蓄
= 劳动者的个人消费额 + 产业资本家的个人消费 + 产业资本家的生产消费 + 产业资本家的储蓄 + 金融资本家的个人消费 + 金融资本家的投资消费 + 金融资本家的个人消费
= 5000 * 80% + 4750 * 20% + 4750 * 70% + 4750 * 10% + 250 * 40% + 250 * 50% + 250 * 10%
= 总个人消费 + 总生产消费 + 储蓄
= （5000 * 0.80 + 4750 * 0.20 + 250 * 0.40） + （4750 * 0.70 + 250 * 0.50） + （5000 * 0.20 + 4750 * 0.10 + 250 * 0.10）
= 5050 + 3450 + 1500
= （5050 + 3450） + 1500
=10000

作为支出的新价值总量 = 总消费 + 总投资
= 总个人消费 + （利润的生产消费额 + 利息的投资额 + 库存商品额）
= （劳动者的个人消费 + 产业资本家的个人消费 + 金融资本家的个人消费） + （利润产生的总生产消费额 + 利息的投资额 + （工资的储蓄额 + 利润的储蓄额 + 利息的储蓄额））
= （5000 * 80% + 4750 * 20% + 250 * 40%） + （4750 * 0.70 + 250 * 50% + （5000 * 0.20 + 4750 * 0.10 + 250 * 0.10））
= 5050 + （3450 + 1500）
= 10000

在这个更复杂的模型下，两种计算方式下的新储蓄额与新库存商品额总是相同的。

因此，无论是在无产者与资本家的二角色模型下，还是在无产者、产业资本家、金融资本家的三角色模型下，皆存在新储蓄—新库存恒等式。

---

总而言之，庸俗经济学关于国民生产总值的两个公式，在概念上存在严重的混乱，从而将不同意义上的总消费混同起来。因此，在这种混乱和混同的条件下，得出的储蓄—投资恒等式，是完全的混乱观念，没有任何价值。真正说来，在类似的模型下，真正能得出的是新储蓄—新库存恒等式。相应模型及新储蓄—新库存恒等式告诉我们，资本主义的扩大再生产受影响于各种储蓄，诸如劳动者、产业资本家、金融资本家等等的储蓄。降低各经济角色的储蓄率，可使他们资金投入消费领域，以在更快的速度和更大的量上实现新价值；或投入投资领域，以更好地实现资本的积累和积聚，等等。
