# 价值形式全过程模拟器（多线程优化版）介绍

## 项目概述

价值形式全过程模拟器是一款创新的经济学教学与研究工具，展现了商品交换关系网络随时间演变的动态过程。本工具基于马克思政治经济学中的价值形式理论，构建了一个可视化模拟系统，能够直观呈现商品交换中形成的复杂网络结构及其演化规律。相关图中的有向边仅代表交换意向，而不是直接对应价值形式。该模拟器还运用了多线程技术，显著提高了运行效率。

## 核心功能

1. **动态网络模拟**：
   - 模拟商品交换关系的随机生成与演化
   - 保存和可视化单向交换、双向交换等交换关系
   - 60个时间步长的完整演化过程

2. **多线程优化架构**：
   - 采用ThreadPoolExecutor实现并行计算
   - 任务队列机制确保线程安全
   - 显著提升大规模网络生成效率

3. **智能产品列表生成**：
   - 集成DeepSeek和Kimi AI接口
   - 自动生成符合历史背景的商品列表
   - 支持自定义产品数量和类型

4. **多维可视化输出**：
   - 生成DOT格式网络图
   - 自动渲染为PNG图像序列
   - 合成动态GIF动画
   - 绘制节点类型分布饼图

5. **交换难度分析**：
   - 实现指数型交换难度计算模型
   - 可视化展示环形交换的复杂度增长

## 技术亮点

- **高效并行处理**：将耗时的图像生成任务分配到多个线程执行
- **智能错误处理**：完善的异常捕获和日志记录机制
- **灵活配置**：支持调整交换概率、时间步长等参数
- **跨平台兼容**：纯Python实现，无需特殊依赖
