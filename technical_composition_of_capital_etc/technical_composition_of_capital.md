> 资本的构成要从双重的意义上来理解。从价值方面来看,资本的构成是由资本分为不变资本和可变资本的比例,或者说,分为生产资料的价值和劳动力的价值即工资总额的比例来决定的。从在生产过程中发挥作用的物质方面来看,每一个资本都分为生产资料和活的劳动力；这种构成是由所使用的生产资料量和为使用这些生产资料而必需的劳动量之间的比例来决定的。我把前一种构成叫做资本的价值构成,把后一种构成叫做资本的技术构成。二者之间有密切的相互关系。为了表达这种关系,我把由资本技术构成决定并且反映技术构成变化的资本价值构成,叫做资本的有机构成。凡是简单地说资本构成的地方,始终应当理解为资本的有机构成。（马克思：《资本论》（第一卷），北京：人民出版社，2009年版，第707页。）

从这个函数图像，可以看出二者之间应该有线性关系。所以我们可进一步分析这里的数学关系。

先梳理这里相关的一些方程，可得：

可变资本 = 可变资本数量 * 可变资本价格，

VC= VCN * VCV,

不变资本 = 不变资本数量 * 不变资本价格，

CC= CCN * CCV,

资本价值构成 = 不变资本 / 可变资本，

VCC = CC / VC,

资本技术构成 = 不变资本数量 / 可变资本数量，

TCC = CCN / VCN.

现在我们想知道，当资本技术构成变化，则资本价值构成会如何变化，于是我们让后者对前者求导，即VCC对TCC求导。

d(VCC) / d(TCC) = d(CC / VC) / d(CCN / VCN).

代入VC和CC的方程，得：

d(VCC) / d(TCC) = d((CCN * CCV) / (VCN * VCV)) / d(CCN / VCN).

设CCV、VCN是常数，则：

d(VCC) / d(TCC) = ((CCV / VCV) * d(CCN / VCN)) / d(CCN / VCN) = CCV / VCV.

也就是说，在其他条件固定不变，只有资本技术构成充当自变量的情况下，资本价值构成对资本技术构成的导数，等于不变资本价格与可变资本价格的比值。

我们现在代入代码里所规定的CCV和VCV，得相应导数的值 = 10 / (0.6 * 12) = 25 / 18 = 1.3888888888888888。通过代码所得的一些值来验算，可知结果是正确的。

另外，我们根据一些基本关系，亦可知：

VCC = (CCN * CCV) / (VCN * VCV) = TCC * (CCV / VCV).

就上式而言，如果CCV、VCV不变，只要简单地知道CCV和VCV的值，则CCV / VCV就是该方程的固定的系数，TCC是该方程的自变量，我们就可从自变量TCC轻易得出因变量VCC。这是一种比较简单的情况，属于一种特例，特殊的地方在于CCV、VCV是不变的。

因此，在不变资本价格和可变资本价格不变的情况下，二者的比值，就是资本技术构成决定资本价值构成的具体的系数。这个结论，应该是独创的。

这两种价格不变，应该是一般情况下的假设，是比较合理的。但经济学的各种范畴之间有十分复杂的关系，所以它们不是绝对不变。只能说，在这个建模的情况下，我们得出的方程是合理的。

随着环节的不断上升，或者约束条件的不断放开，等等，情况会变得十分复杂。所以，我们在这个环节上得出的正确的东西，或许在更高环节上就会多多少少失去其原本的有限真理性云云，但同时更靠近完整的现实性。
