# 再生产视角下剩余价值生产的环节式上升，兼论马克思经济学对数学的需要

我们在《资本论》第一卷上所了解的剩余价值率和利润率，是一般的概念。它们的形式是这样的：

剩余价值率：

$mr = \frac{m}{v}$

利润率：

$pr = \frac{m}{c + v}$

从这二者，可得抽象的生产中剩余价值率与利润率之比：

$\frac{mr}{pr} = (\frac{v}{c + v})^{-1}$

然而，其中有很多具体的规定性还没有展开。

因为，生产不是一次的生产，而是不断的生产，也就是说**再生产**。

就再生产中的单次生产循环而言，每次的预付资本中都应该多多少少包含上次生产循环中的剩余价值，若假设不包含则得到简单再生产。

这里的剩余价值，在上次的生产循环中实现为货币形式之后，需要分出来（1）资本家的个人收入，这部分不进入再生产，此外还应该分配到以下形式中：（2）再投入到不变资本上的剩余价值，（3）再投入到可变资本上的剩余价值。

因此，为了研究再生产中的剩余价值相关问题，从这里的分析中可以知道，至少应该加入的参数有：资本家的个人收入，剩余价值分为不变资本、可变资本的比例。

于是，我们就可以得到比如再生产中剩余价值率与利润率的函数：

$mr = \frac{m}{v_p + (mg_p - cc_p) \times vrr}$

$pr = \frac{m}{c_p + v_p + mg_p - cc_p}$

从这二个率的函数，可得到再生产中二者的比：

$\frac{mr}{pr} = (\frac{v_p + (mg_p - cc_p) \times vrr}{c_p + v_p + mg_p - cc_p})^{-1}$

诸参数的具体意义，请参阅[这篇文章](https://zhuanlan.zhihu.com/p/491074591?)。

对比生产和再生产视角下各种相对应的函数，可知再生产这个环节上的关系更复杂了，更具体了，更靠近现实了，也就是说，这个环节是更高的环节。

不过这里的上升运动还是比较有步骤的，不是突然上升到很高的阶段。我们单纯对比一下生产和再生产下的剩余价值率与利润率之比，也可以看出来一定的对应关系。

一般的生产循环中的$v$，从更具体的再生产环节上来看，包含了上一次循环中的$v_p$，以及从上一次循环的剩余价值中分来的追加的可变资本，这个追加里面有三个参数：上一次循环的毛剩余价值和资本家的个人消费，以及本次循环的剩余价值到可变资本的再投资比例。

而一般生产中的预付资本$c + v$，从更具体的再生产环节上来看，包含了上一次循环中的不变资本、可变资本，再加上追加了的新投资。这部分新投资，从这里的函数需求来看，不需要区分可变资本与不变资本，只需要知道它是上一次循环中的毛剩余价值减去上一次循环中的资本家个人消费，即可。

---

可以看到，马克思经济学同样需要数学，而且是特别地需要。应该争取用数学的形式描述好、证明好马克思的理论。

之前，我也已经用数学甚至编程的方式，描述了剩余价值率对可变资本的绝对的或相对的替代关系。

现在网络上总是喜欢说什么“多少人干多少人的活，拿多少人的工资”。这实际上是一种模糊的表象。马克思早就指出，这是一种剩余价值率对可变资本的替代关系。在《资本论》第一卷第九章中，马克思明确提到了这种替代模型。

但他的模型很粗糙，而且是就工作日的绝对界限来谈的绝对替代模型。我给他发展到了相对替代模型的新高度。并且也发觉了不科学的翻译，明确发现了马克思经济学中亦有的“替代”这个经济学研究范式。

如果不是坚持研究这种替代的数学模型，就很难发现这里的重大问题，更不可能随随便便得到新的发展。
